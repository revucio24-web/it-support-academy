Modul 12Falsche DNS-Server-Einstellung

Der Benutzer kann Webseiten nicht aufrufen (Name nicht auflösbar), aber `ping 8.8.8.8` funktioniert

Modul 12Firewall blockiert legitimen Datenverkehr

Eine Anwendung (z. B. RDP, Drucker, Datenbank) kann nicht auf den Server zugreifen — die Firewall blockiert die Verbindung

Modul 12VLAN-Fehlerkonfiguration

Gerät im Netzwerk ist mit dem Switch verbunden, erhält keine IP-Adresse oder kann nicht mit anderen Geräten kommunizieren

Modul 12Veralteter DNS-Cache

Modul 13PowerShell-Skript wird nicht ausgeführt

Fehlermeldung „Das Ausführen von Skripten ist auf diesem System deaktiviert"

Modul 13Cmdlet wird nicht erkannt

Modul 13Pipeline-Fehler bei fehlenden Eigenschaften

Leere Ausgabe oder Fehlermeldung beim Verketten von Befehlen

Modul 13Zugriffsverweigert bei Remote-Befehlen

Modul 14Gerät wird nicht automatisch in Intune registriert

Gerät ist mit Entra ID verbunden, erscheint aber nicht in Intune

Modul 14App-Installation schlägt fehl, obwohl App zugewiesen ist

Benutzer sieht App im Company Portal, Installation schlägt aber fehl

Modul 14Benutzer kann sich nicht anmelden — Conditional Access blockiert Zugriff

Benutzer meldet sich mit korrekten Zugangsdaten an, erhält aber Zugriffsverweigerung

Modul 14Passwort-Reset funktioniert nicht — SSPR konfiguriert falsch

Benutzer kann Passwort nicht über Self-Service Password Reset (SSPR) zurücksetzen

Modul 15Backup ohne Recovery-Test

Modul 15System-Image auf anderer Hardware wiederhergestellt

BSOD (Blue Screen) nach Systemimage-Wiederherstellung auf einen anderen PC

Modul 15Patches ohne Test direkt auf Produktivsysteme

Modul 16Known Error nicht in der KEDB dokumentiert

Modul 16Dokumentation unvollständig oder unverständlich

Kollege kann übernommenes Ticket nicht bearbeiten

Modul 17Zeitmanagement in der Prüfung schlecht

Nicht alle Fragen bearbeitet, obwohl die Antworten gewusst wurden

Modul 17PBQs (Performance-Based Questions) falsch angegangen

Fragen übersprungen oder falsch gelöst, obwohl der Stoff bekannt war

Modul 17Dokumentation unvollständig

Kollege kann übernommene Tickets nicht bearbeiten, fehlende Infos

Modul 17Prüfungsangst und unvorbereiteter Start
